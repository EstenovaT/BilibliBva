一、项目目标
────────────────────────────────────────────────────────────
以 B站视频解析脚本为基础，交付「网页在线解析」服务：
  ① 本地版：Python 后端 + 网页，一键启动即可本地使用
  ② 云端版：后端用 JS 重写为 Cloudflare Worker，
     纯静态网页也能在线解析（可部署到 Workers / Pages）
  ③ 解析域名：bva.estenova.top（永久解析链接域名，可配置）

三、网页功能（src/webui/index.html）
────────────────────────────────────────────────────────────
  1. 输入框：粘贴 B 站链接 / BV 号 / AV 号，点击「解析」
  2. 展示视频信息：标题、UP主、分区、时长、发布时间、
     播放/弹幕/评论/点赞/投币/收藏/转发数、封面图、简介
  3. 分P选择 + 画质选择（360P ~ 4K）
  4. 结果展示：mp4 临时直链（一键复制）、永久解析链接、B站原链接
  5. 网页内播放：直接播放 + 代理播放（后端开启代理时显示按钮）
  6. 移动端适配，粉色简洁 UI

四、API 路由设计（Python 与 Worker 版一致）
────────────────────────────────────────────────────────────
  GET /                       → 返回在线解析网页 index.html（默认版：仅直接播放）
  GET /ex                     → 完全版网页（隐藏入口）：开启代理播放
  GET /api/resolve?url=&p=&qn= → JSON：
                                { title, uploader, cover, stat,
                                  mp4_url, perm_link, quality,
                                  proxy_enabled, ... }
  GET /?bv=xxx&p=N             → 兼容 bot 永久链接：302 跳转 mp4 直链
  GET /pic?url=...             → 封面图片代理（带 B 站 Referer）
  GET /proxy?url=...           → 视频代理播放（需 /ex 完全版或 PROXY=1）

【完全版隐藏入口说明】
  在线版（Worker）默认页面只保留「直接播放」+ 复制直链，不显示代理播放。
  在域名后添加 /ex（如 https://bva.estenova.top/ex）可打开完全版网页：
  - 前端检测路径为 /ex，自动在 API 与 /proxy 请求中附带 ex=1
  - Worker 据此返回 proxy_enabled=true（显示「代理播放」按钮）并放行 /proxy
  - 全局开关 PROXY=1 时所有页面均为完全版（不推荐公开开启，消耗流量）

五、本地运行
────────────────────────────────────────────────────────────
【Python 版】（需要 Python 3.7+，无需第三方依赖）
  python src/script/start_local.py            # 一键启动（8080，自动开浏览器）
  python src/script/start_local.py --check    # 环境自检
  python src/script/test_driver.py            # 6 项接口自测

【Worker 版本地预览】（需要 Node.js 18+ 与 pnpm）
  cd src/worker
  pnpm install
  pnpm dev                    # wrangler dev → http://localhost:8787

六、Cloudflare 部署方案（Worker 版，推荐）
────────────────────────────────────────────────────────────
【为什么用 Worker】
  后端逻辑（调用 B 站 API、防盗链代理、302 跳转）必须在服务器端执行；
  Cloudflare Pages 纯静态托管跑不了 Python，因此将后端用 JS 重写为
  Cloudflare Worker，静态网页由 Worker 的 ASSETS binding 一并托管。

【部署步骤】
  1. 安装依赖并登录：
       cd src/worker
       pnpm install
       pnpm login             # 授权 Cloudflare 账号
  2. 部署：
       pnpm deploy            # 输出 https://bva-resolve.<子域>.workers.dev
  3. 绑定自定义域 bva.estenova.top：
       - 域名先在 Cloudflare 添加站点（Nameserver 接入）
       - Worker 控制台 → Settings → Domains → Add 自定义域
       - 绑定后永久链接自动变为 https://bva.estenova.top/?bv=...&p=...
  4. GitHub 自动部署（可选）：
       Cloudflare 控制台 → Workers Builds（或 Pages + Workers）
       连接本 GitHub 仓库，构建命令：
         cd src/worker && pnpm install && pnpm deploy
       push 后自动构建部署

【环境变量（wrangler.toml [vars]）】
  PROXY = "0"     # 1 时开启 /proxy 代理播放（默认关闭，省流量）

七、防盗链处理
────────────────────────────────────────────────────────────
  - 后端调用 B 站 API / 封面 / 视频流时均携带
    Referer: https://www.bilibili.com
  - 浏览器直连跨域直链会被 B 站 403（防盗链）：
    ├─ 方案 1（默认）：提供「复制直链」按钮，配合下载工具
    │    （IDM/迅雷等）手动带 Referer 下载
    └─ 方案 2（可选）：后端 /proxy 代理播放（消耗服务器/Worker 流量，
        默认关闭；网页在后端未开启时自动隐藏「代理播放」按钮）
  - Worker 版免费额度限制：代理整段视频流可能超时，公开站建议
    保持 PROXY=0

八、验收标准
────────────────────────────────────────────────────────────
  1. 仓库结构完整：src/script、src/server、src/webui、src/worker
  2. Python 本地 6 项接口自测全部通过
  3. pnpm install && pnpm dev 本地可预览（网页 + API + 302 + /pic）
  4. pnpm deploy 部署成功，*.workers.dev 可在线解析
  5. 绑定 bva.estenova.top 后永久链接域名正确
  6. 网页上代理播放按钮状态与后端 proxy_enabled 一致

九、已知限制与风险
────────────────────────────────────────────────────────────
  - B 站风控（-412）：异常 IP/频率触发时解析失败，稍后重试或换网络；
    Cloudflare 出口 IP 触发概率相对较高
  - 画质降级：1080P+/4K 依赖登录态，未登录会被 B 站自动降级
  - Worker 免费额度：请求数/CPU 时长有限，公开站注意用量
  - 代理播放消耗流量，公开站默认关闭
